# Mac Live Notch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** On macOS, a click-through overlay wrapped around the MacBook notch
showing live recording state, WPM, fillers/min, and optionally the
timer/stopwatch and the upcoming script words.

**Architecture:** A second Tauri webview window (`notch`), opened and closed by
a Rust command. objc2 raises it above the menu bar and places it around the
notch. The main window owns all state and pushes one small JSON payload to it
with `emitTo("notch", "notch", …)`. The notch page only renders that payload.

**Tech Stack:** Tauri 2.11 (Rust), objc2 0.6 / objc2-app-kit 0.3.2, TypeScript +
Vite 6, bun for `*.check.ts` scripts.

**Spec:** `docs/superpowers/specs/2026-10-21-mac-notch-design.md`

## Global Constraints

- macOS only. On Linux and Windows `notch_show` returns `Ok(())` and the
  Settings "Notch" panel is removed from the DOM.
- No new crates or npm packages. Feature flags on existing ones only.
- `WING = 110.0` pt, `ROW = 28.0` pt, `PILL_W = 360.0` pt, `PILL_H = 32.0` pt
  (spec values). The CSS `--wing` and `--row` in `notch.html` must equal
  `WING` and `ROW`.
- Window level `NSStatusWindowLevel` (25). Collection behaviour
  `CanJoinAllSpaces | Stationary | FullScreenAuxiliary | IgnoresCycle`.
- Settings keys: `speech.notch` (default off), `speech.notch.time` (default
  on), `speech.notch.script` (default on).
- The notch never takes focus and lets every click through.
- Pushes at most every 250 ms (the `tickClock` interval). Identical payloads
  are not re-sent.
- **Shared `target/`:** the user runs `tauri dev` alongside you. Every cargo
  command in this plan uses
  `CARGO_TARGET_DIR=/tmp/claude-1000/-home-marsont-speech/notch-target`, or
  their dev build breaks. The first build there compiles all deps from
  scratch, so allow ~10 min.
- Commits carry no Claude co-author or attribution trailer.

## Review Focus

1. **Notch opened while idle stays blank.** A fresh notch window misses pushes
   sent before its page has loaded, and nothing changes while idle to send
   another. Expect it to show the current stats straight away. Covered by the
   `notch-ready` handshake in Task 3 (page) and Task 4 (main), checked
   manually on the Mac.
2. **Settings search on Linux brings the hidden panel back.** `filterSettings`
   resets `panel.hidden` on every keystroke, so Linux users would see a dead
   Notch panel. Expect it never to appear. Task 4 removes the panel from the
   DOM instead of hiding it; check by typing "notch" into the settings search
   on Linux.
3. **Script toggle on but no script loaded, or the script finished.** Expect
   no stray black row. `notchState` keeps `script: ""` (row space kept,
   invisible) apart from `null` (row gone). Tested in Task 1, styled in Task 3.
4. **Startup with Show notch saved on.** Expect the notch to reopen with
   Timer/Script already applied. Task 4 binds the time and script toggles
   before `set-notch`, so `notchTime`/`notchScript` are set before the first
   `notch_show`.
5. **`notch_show` fails on the Mac** (e.g. a missing objc2 feature at runtime
   or a window build error). Expect the switch to flip back off and the
   setting not to stick. Task 4's `setNotch` catch path.

Deviation from the spec, on purpose: the spec put the page listener in
`src/notch.ts`. It lives in an inline module script in `notch.html` instead,
so that `main.ts` importing `src/notch.ts` doesn't also register the notch
page's listener in the main window. Likewise, the page hardcodes the dark
theme's green and amber (`#30d158` / `#ffd60a`) rather than importing
`styles.css`, because the notch is always black and `styles.css` would paint
an opaque body background.

// The live notch's payload (macOS; src-tauri/src/notch.rs opens the window,
// notch.html renders it). Pure; checked by notch.check.ts.

export interface NotchState {
  rec: boolean;
  time: string | null; // null when Timer/stopwatch is off
  wpm: number;
  band: "in" | "out" | ""; // WPM against the preset's target band; "" before any words
  fpm: string; // fillers/min, 1 decimal
  script: string | null; // null = Script off; "" = on but nothing ahead
}

export function notchState(i: {
  rec: boolean;
  time: string | null;
  wpm: number;
  low: number;
  high: number;
  fpm: number;
  script: string | null;
}): NotchState {
  const band = i.wpm === 0 ? "" : i.wpm >= i.low && i.wpm <= i.high ? "in" : "out";
  return { rec: i.rec, time: i.time, wpm: i.wpm, band, fpm: i.fpm.toFixed(1), script: i.script };
}

// The next `n` script words from the read-along cursor, as written (punctuation
// between them kept), whitespace collapsed to single spaces.
export function scriptAhead(text: string, tokens: { start: number; end: number }[], cursor: number, n = 8): string {
  if (cursor >= tokens.length) return "";
  const last = tokens[Math.min(tokens.length, cursor + n) - 1];
  return text.slice(tokens[cursor].start, last.end).replace(/\s+/g, " ");
}
```

//! Live notch (macOS): a click-through overlay wrapped around the MacBook
//! notch, showing the live cues the main window pushes to it (src/notch.ts,
//! notch.html). A no-op on other platforms.

// Keep in step with --wing / --row in notch.html.
const WING: f64 = 110.0; // each side of the notch gap
const ROW: f64 = 28.0; // the script row under the bar
const PILL_W: f64 = 360.0; // no notch: a pill this wide
const PILL_H: f64 = 32.0;

#[derive(Debug, Clone, Copy, PartialEq)]
pub struct Rect {
    pub x: f64,
    pub y: f64,
    pub w: f64,
    pub h: f64,
}

/// The overlay's frame in AppKit's global, bottom-left-origin points,
/// top-aligned on `screen`. `notch` is the gap's x-range (global); None centres
/// a pill instead. `bar_h` is the menu bar height beside the notch.
#[cfg_attr(not(target_os = "macos"), allow(dead_code))] // used by the macOS placement and tests
pub fn notch_frame(screen: Rect, notch: Option<(f64, f64)>, bar_h: f64, script: bool) -> Rect {
    let row = if script { ROW } else { 0.0 };
    let (x, w, h) = match notch {
        Some((l, r)) => (l - WING, r - l + 2.0 * WING, bar_h + row),
        None => (screen.x + (screen.w - PILL_W) / 2.0, PILL_W, PILL_H + row),
    };
    Rect { x, y: screen.y + screen.h - h, w, h }
}

/// Opens (or re-places, e.g. after the Script toggle changes its height) or
/// closes the notch window.
#[tauri::command]
pub async fn notch_show(app: tauri::AppHandle, on: bool, script: bool) -> Result<(), String> {
    #[cfg(target_os = "macos")]
    return mac::show(&app, on, script);
    #[cfg(not(target_os = "macos"))]
    {
        let _ = (app, on, script);
        Ok(())
    }
}

#[cfg(target_os = "macos")]
mod mac {
    use super::{notch_frame, Rect};
    use objc2::MainThreadMarker;
    use objc2_app_kit::{NSScreen, NSStatusWindowLevel, NSWindow, NSWindowCollectionBehavior as B};
    use objc2_foundation::{NSPoint, NSRect, NSSize};
    use tauri::{Manager, WebviewUrl, WebviewWindowBuilder};

    pub fn show(app: &tauri::AppHandle, on: bool, script: bool) -> Result<(), String> {
        let existing = app.get_webview_window("notch");
        if !on {
            if let Some(w) = existing {
                w.close().map_err(|e| e.to_string())?;
            }
            return Ok(());
        }
        let win = match existing {
            Some(w) => w,
            // Built hidden; `place` orders it front without activating the app,
            // so Keynote (or whatever is presenting) keeps focus.
            None => WebviewWindowBuilder::new(app, "notch", WebviewUrl::App("notch.html".into()))
                .title("Notch")
                .transparent(true)
                .decorations(false)
                .focusable(false)
                .shadow(false)
                .resizable(false)
                .skip_taskbar(true)
                .visible_on_all_workspaces(true)
                .always_on_top(true)
                .visible(false)
                .build()
                .map_err(|e| e.to_string())?,
        };
        win.set_ignore_cursor_events(true).map_err(|e| e.to_string())?;
        let ns = win.ns_window().map_err(|e| e.to_string())? as usize; // raw pointers aren't Send
        // AppKit only on the main thread. The window outlives this call: Tauri owns it.
        win.run_on_main_thread(move || unsafe { place(&*(ns as *const NSWindow), script) })
            .map_err(|e| e.to_string())
    }

    // Above the menu bar (Tauri's always-on-top level sits below it, and macOS
    // pushes the frame down), on every Space and over fullscreen apps, around
    // the notch of the built-in display, else a pill on the main screen.
    // ponytail: placed once per open; toggle off/on after a display change.
    unsafe fn place(w: &NSWindow, script: bool) {
        let mtm = MainThreadMarker::new_unchecked();
        let notched = NSScreen::screens(mtm).iter().find(|s| s.safeAreaInsets().top > 0.0);
        let Some(screen) = notched.or_else(|| NSScreen::mainScreen(mtm)) else { return };
        let f = screen.frame();
        let bar_h = screen.safeAreaInsets().top;
        let gap = (bar_h > 0.0).then(|| {
            let (l, r) = (screen.auxiliaryTopLeftArea(), screen.auxiliaryTopRightArea());
            (l.origin.x + l.size.width, r.origin.x)
        });
        let screen_rect = Rect { x: f.origin.x, y: f.origin.y, w: f.size.width, h: f.size.height };
        let r = notch_frame(screen_rect, gap, bar_h, script);
        w.setLevel(NSStatusWindowLevel);
        w.setCollectionBehavior(B::CanJoinAllSpaces | B::Stationary | B::FullScreenAuxiliary | B::IgnoresCycle);
        w.setHasShadow(false);
        w.setIgnoresMouseEvents(true);
        w.setFrame_display(NSRect::new(NSPoint::new(r.x, r.y), NSSize::new(r.w, r.h)), true);
        w.orderFrontRegardless();
    }
}
```

```ts
// --- Live notch (macOS) --------------------------------------------------------
// notch.html renders what this pushes; src-tauri/src/notch.rs opens the window.
// The latest dock values are kept here so pushes from tickClock don't recompute.
let notchOn = false;
let notchTime = true;
let notchScript = true;
let notchWpm = 0;
let notchFpm = 0;
let scriptCursor = 0;
let lastNotch = ""; // JSON of the last push; identical pushes are skipped

function pushNotch() {
  if (!notchOn) return;
  const p = PRESETS[currentPreset];
  const timer = drillMs > 0 || prepEndsAt > 0; // same choice as #countdown vs #clock
  const s = notchState({
    rec: recording,
    time: notchTime ? ($(timer ? "countdown" : "clock")?.textContent ?? "") : null,
    wpm: notchWpm,
    low: p.wpmLow,
    high: p.wpmHigh,
    fpm: notchFpm,
    script: notchScript ? scriptAhead(scriptText, scriptTokens, scriptCursor) : null,
  });
  const json = JSON.stringify(s);
  if (json === lastNotch) return;
  lastNotch = json;
  emitTo("notch", "notch", s).catch(() => {});
}

// Opens, re-places (Script changes its height) or closes the notch. On failure
// the switch flips back off and stays off.
async function setNotch(on = notchOn) {
  notchOn = on;
  try {
    await invoke("notch_show", { on, script: notchScript });
    lastNotch = "";
    pushNotch();
  } catch (e) {
    console.error("notch:", e);
    notchOn = false;
    save(NOTCH_KEY, "0");
    const box = $<HTMLInputElement>("set-notch");
    if (box) box.checked = false;
  }
}
```
